## Getting Started

First, run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the
result.

## Protección de datos en producción

- Configura `NEXT_PUBLIC_EMAIL_TEMPLATE_RIGHTS` con una plantilla de EmailJS
  dedicada a las solicitudes de derechos.
- Mantén `NEXT_PUBLIC_REVIEW_API_URL` apuntando a un backend bajo control de la
  empresa, con un procedimiento probado para localizar y borrar reseñas cuando
  se solicite.
- Revisa los acuerdos de tratamiento, transferencias internacionales y plazos de
  borrado de EmailJS, del backend de reseñas y de cualquier proveedor que se
  añada antes de publicar cambios.

You can start editing the page by modifying `app/page.tsx`. The page
auto-updates as you edit the file.
